My Professional Projects

AI-Powered Travel Planner

Core Problem: To create a clear, AI-driven travel planning tool that specifically helps users generate optimized, multimodal travel recommendations, addressing the need for comprehensive and personalized trip planning.

My Role: I was responsible for the entire development of this project, working closely with assistance from Innomatics Research Labs. This involved integrating AI models, designing the user interface, and ensuring functional, reliable output.

Technologies: LangChain, Google GenAI APIs (Google Gemini AI), Streamlit, Python.

Challenges & Solutions:

  • Ensuring Accurate & Contextual Responses: Addressed through careful prompt engineering and fine-tuning LangChain & Google GenAI API integration.
  • Optimizing Multimodal Recommendations: Achieved by structuring LangChain prompts to effectively extract and synthesize information across various travel modes.

Impact: Successfully generated optimized travel plans (flights, trains, buses, cabs) with estimated costs/durations. The interactive Streamlit UI provided quick, reliable, and cost-effective options, demonstrating a practical application of Generative AI.

LoRaWAN-Based Real-Time Vehicle Tracking System

Core Problem: To address the inefficiency and high cost of existing vehicle tracking methods over a large 600-acre campus, developing a more affordable and power-efficient alternative to traditional GPS trackers.

My Role: As part of a four-member team, my key responsibility was to synchronize the Arduino code with the GPS module for the Heltec LoRaWAN module and integrate it with the UI dashboard, ensuring accurate real-time location updates.

Technologies: Heltec LoRaWAN v3 modules, U-blox NEO 6M GPS, Arduino, SPI, I2C, UART, HTML, CSS, JavaScript, Leaflet.

Challenges & Solutions:

  • Heltec Board Configuration: Overcame initial challenges with the specific configuration through dedicated effort and successful integration with GPS and Arduino.
  • Cloud Integration: Resolved uncertainty by directly connecting the system with AI-generated HTML code for the UI dashboard, providing functional visualization without complex cloud setup.

Impact: Proposed solution aimed to reduce system cost by 70% and power consumption by 80% compared to traditional GPS trackers for a 15km circulation area, significantly enhancing operational efficiency.
